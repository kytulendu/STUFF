# Thai Display Font

Thai display font for EGA and VGA.

For use with Thai 8 line programs.

Available in Kaset, Loxley and Sahaviriya (SIC) Thai character encoding.

Font lists:

* LYVGA : Loxley Thai character encoding, modified from `RVGA` font.
* QX10 : From EPSON QX-10 (Q10GGS board) that distributed in Thailand by Sahaviriya Infotech Computer (SIC). It use Sahaviriya (SIC) Thai character encoding.
* REGA : Kaset Thai character encoding, from Rajavithi Word PC `REGA.COM`.
* RVGA : Kaset Thai character encoding, from Rajavithi Word PC `RVGA.COM`.
