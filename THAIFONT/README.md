# Thai Display Font

Thai display font for EGA and VGA.

For use with Thai 8 line programs.

Available in TIS-620, Kaset, Loxley and Sahaviriya (SIC) Thai character encoding.

Font lists:

* CODEKU2 : Thai 8x14 font from IRC Thai Driver; Kaset Thai character encoding.
* CODEKU3 : Thai 8x16 font from IRC Thai Driver; Kaset Thai character encoding.
* CODESIC : Thai 8x16 font from IRC Thai Driver; Sahaviriya (SIC) Thai character encoding.
* CODESIC2 : Thai 8x14 font from IRC Thai Driver; Sahaviriya (SIC) Thai character encoding.
* CODESIC3 : Thai 8x16 font from IRC Thai Driver; Sahaviriya (SIC) Thai character encoding.
* LYVGA : Modified from `RVGA` font; Loxley Thai character encoding.
* QX10 : From EPSON QX-10 (Q10GGS board) that distributed in Thailand by Sahaviriya Infotech Computer (SIC); Sahaviriya (SIC) Thai character encoding.
* REGA : Rajavithi Word PC `REGA.COM`; Kaset-RW Thai character encoding.
* RVGA : Rajavithi Word PC `RVGA.COM`; Kaset-RW Thai character encoding.
* TGAPLUS : Sahaviriya Thai Graphic Adaptor Plus 8x16 font, seems to converted from EGA 8x14 font; TIS-620 SIC Thai character encoding.
* THAICOUR : Thai Courier from Thai Easy Writer 4.1; Kaset Thai character encoding.
* TSME : Thai System Manager (TSM) 8x14 font; TIS-620 SIC Thai character encoding.
* TSMV : Thai System Manager (TSM) 8x16 font; TIS-620 SIC Thai character encoding.
